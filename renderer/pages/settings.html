السماح عبر جدار حماية Windows

لكي يتصل الجهاز الفرعي بالرئيسي عبر الشبكة، يجب السماح لهذا البرنامج باستقبال الاتصالات على المنافذ 4512–4521 (شبكة خاصة).

اضغط «محاولة السماح تلقائياً» ليظهر طلب التحكم بالحساب (UAC) — وافق عليه لإضافة القاعدة. أو اسمح يدويًا من:

الإعدادات ← الخصوصية والأمان ← جدار حماية Windows ← السماح لتطبيق عبر جدار الحماية ← تفعيل هذا البرنامج للشبكات الخاصة.
