# ZMT PIECE

نظام **ZMT PIECE** لإدارة نقاط البيع — تطبيق سطح مكتب عربي (Windows) لإدارة المحلات والمخزون والفواتير والمبيعات.

## التنزيل

يُحمَّل أحدث إصدار من صفحة الإصدارات:

https://github.com/mhmdthr96-arch/ZMT-PIECE/releases/latest

اختر الملف المناسب لجهازك:

| النظام | المعمارية | اسم الملف |
| --- | --- | --- |
| Windows 10 / 11 | 64-bit | `ZMT PIECE-Setup-<version>-x64.exe` |
| Windows 10 / 11 | 32-bit | `ZMT PIECE-Setup-<version>-ia32.exe` |
| Windows 7 | 64-bit | `ZMT PIECE-Setup-<version>-win7-x64.exe` |
| Windows 7 | 32-bit | `ZMT PIECE-Setup-<version>-win7-ia32.exe` |

> ملاحظة: كل ملفات التثبيت مضغوطة ويحمل اسمها رقم إصدارها.

## التحديثات التلقائية

يتحقّق التطبيق تلقائيًا من ملف `update.json` المرفق بكل إصدار على GitHub، ويعرض إشعارًا بالتحديث الجديد مع إمكانية التنزيل والتثبيت مباشرة من داخل البرنامج.
